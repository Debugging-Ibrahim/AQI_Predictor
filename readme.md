## What is AQI Predictor?

AQI Predictor is an end-to-end machine learning system designed to forecast the Air Quality Index (AQI) for **Faisalabad, Punjab, Pakistan**.

It combines:

- Live weather and air-quality data from **Open-Meteo**
- Historical feature storage in **Supabase/Postgres**
- Time-series feature engineering
- Multiple machine-learning algorithms
- Horizon-specific model selection for **24h, 48h, and 72h**
- **SHAP**-based explainability
- Automated hourly data and inference updates
- Automated daily model retraining
- A React dashboard deployed on **Railway**

Most recurring data, inference, and retraining work is automated through GitHub Actions.

## Machine Learning

The project benchmarks:

- Ridge Regression
- Random Forest
- SVR
- XGBoost
- LightGBM
- CatBoost
- PyTorch LSTM

The production architecture is **horizon-specific**, so the same model is not forced onto every forecast horizon.

### Current production configuration

| Forecast | Model | Preprocessor | Training strategy |
|---|---|---|---|
| 24h | **SVR** | StandardScaler | Exponential recency weighting |
| 48h | **SVR** | RobustScaler | Smog-aware weighting in automated retraining |
| 72h | **CatBoostRegressor** | None | Standard unweighted fit |

## Model Performance

The evaluation uses chronological time-series splits and a **72-hour embargo buffer** between training and test data.

### Audited production benchmark

| Horizon | Model | RMSE | MAE | R² | Persistence RMSE | Improvement |
|---|---|---:|---:|---:|---:|---:|
| 24h | SVR + StandardScaler | **22.81** | **17.49** | **0.7224** | 28.25 | **19.24%** |
| 48h | SVR + RobustScaler | **29.91** | **22.77** | **0.4860** | 35.00 | **14.53%** |
| 72h | CatBoost | **31.67** | **24.22** | **0.3899** | 38.14 | **16.96%** |

## Engineering Decisions

### 72-hour embargo

A 72-hour gap is used between training and test data to reduce overlap caused by multi-step targets.

### Chronological evaluation

The project treats AQI as a time series, so evaluation is chronological rather than randomly shuffled.

### Persistence baseline

The models are compared against a simple baseline:

```text
Future AQI ≈ Current AQI
```

### Controlled data-volume experiments

The project compared 1.5 years and 3 years of training data on a frozen test window to isolate the effect of training-data volume.

### Artifact verification

Saved `.joblib` objects were loaded and checked to ensure their actual model types matched the documented production configuration.
